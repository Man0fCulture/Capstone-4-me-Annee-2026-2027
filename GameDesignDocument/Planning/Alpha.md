# Alpha — 10 February 2027

**Objective:** make the main route coherent from the start to the boss, with the PoC systems integrated into the game.

This milestone expands the December prototype into two connected levels, a boss arena, four main missions and the three selected enemy types. Distinct moves and animations progressively replace the PoC's four reused attacks across later milestones; the twelve-move starting catalogue is a broader content target.

| Work | Expected output | Completion criterion | Quantity |
|---|---|---|---|
| Main route | Connected levels and missions | A new game can complete the four missions in narrative order, return to Emmanuel and reach the boss | 2 levels, 1 arena, 4 missions |
| Enemy behaviour | Combat profiles and behaviours from playtests | Each type uses its selected attacks and its own launch/stagger reactions; encounters can be won and lost | 3 enemy types |
| Progression and configuration | Purchases and equipment integrated into the route | Players earn money, select purchases, use acquired moves and can keep a short combo | 3 or 4 ground slots and 3 aerial slots; produced catalogue documented |
| Session continuity | Saving and resuming tested in missions | Loading a checkpoint restores objectives, relevant enemies and acquisitions present in that save | Verification in all 4 missions |
| Initial balance | Value table and playtest report | Build values for damage, HP, timers, style, stagger and prices are recorded; observed problems are identified | 1 value table and 1 feedback list |
| Interfaces | Usable shop, configuration and objectives | Menus show owned moves and available purchases; configuration is disabled in combat | 1 shop, 1 configuration menu and mission tracking |

**Expected delivery:** playable PC alpha build, integrated-content documentation, known bugs, balance values and a post-mortem.

**Dependencies and risks:** attacks and camera must have been tested; dialogue, interaction and saving must work together. Additional move variants will be selected according to their value and production cost.

**Hunts:** when the bestiary provides the expected variety, define the six contracts and their completion criteria, then schedule integration. This remains deferred until that condition is met.

**Integration and fixes:** last 7 days for complete-route testing, progression-blocking fixes and build preparation.
