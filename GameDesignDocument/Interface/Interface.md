# User Interface

The interface supports player decisions: HP, style points and rank when non-zero, the active target, special-move readiness and the mission objective.

The shop displays prices, owned moves and available slots. The configuration menu shows beginner, follower and finisher slots for both modes, ground and aerial configurations, launchers and the special.

The Game Over screen provides a return to the latest checkpoint. Screen layouts, the stagger gauge and interaction prompts will be developed during integration.
