# Style

Successful hits grant style points and progress through C → B → A → S → SS → SSS. At 0 points, no rank is displayed. With a non-empty gauge, C is the lowest displayed rank.

Variety grants a bonus: switching modes, moving between ground and aerial combat, and using different moves. Players can also build style while staying in one mode. A successful finisher grants a bonus.

A missed move grants no style points. Repeating the same sequence continuously grants progressively fewer points. After a short interval without a successful hit, the gauge gradually decreases towards 0.

Dodging or receiving a hit immediately removes one rank. At C, the gauge is emptied and the rank disappears. The points retained when losing a rank above C will be specified during playtests.

Style increases damage. Sword mode receives a visual explosion effect; pistol mode gains additional range. Affected ranks, bonus values and moves remain to be tuned. The visual explosion is planned; any effect on the damage area remains an open option.
