# Controller Inputs

Button names use PlayStation controller labels.

| Input | Action |
|---|---|
| Square | Weapon 1 attack, sword mode |
| Triangle | Weapon 2 attack, pistol mode |
| Square + Triangle simultaneously | Special move, after purchasing its slot |
| Stick away from the target + Square or Triangle | Equipped launcher for the selected mode |
| Circle | Ground or aerial dodge |
| Cross (X) | Jump |
| R1 | Manual lock-on |
| Directional buttons | Change target |
